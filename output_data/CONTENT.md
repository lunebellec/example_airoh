# Output Data

Generated by `invoke run`. All files are **ignored by Git** (see `.gitignore`).

## Connectivity step (`invoke run-connectivity`)

- **`connectome_sub{idx}.npy`** — vectorized upper-triangle correlation matrix for subject `idx` (shape: 2016 = 64×63/2 ROI pairs). One file per subject (000–065).
- **`connectomes.npz`** — aggregated feature matrix `X` (66 × 2016) and age labels `y` (`"child"` / `"adult"`).

## Classification step (`invoke run-classify`)

- **`classification_results.json`** — accuracy metrics: CV accuracy per fold, CV mean, test accuracy, permutation p-value.
- **`classification_predictions.npz`** — train/test labels and predictions, plus `feat_matrix` (64×64 symmetric SVC weight matrix for brain visualization).

## Figures (`invoke run-notebooks`)

- **`feature_matrix.png`** — subjects × features connectivity heatmap.
- **`confusion_matrices.png`** — confusion matrices for CV (training set) and held-out test set.
- **`connectome_weights.png`** — SVC feature importance plotted on brain (BASC 64 parcellation).
- **`feature_importance_matrix.png`** — SVC weight matrix as a 64×64 ROI correlation-style plot.
